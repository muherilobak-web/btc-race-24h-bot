A regime-aware trend-following bot for Coinbase Wrapped BTC (cbBTC) vs USDC: it only buys when the trend is confirmed up (fast SMA above a rising slow SMA, close clear of it, positive 24-bar momentum) and exits on a trailing stop or a broken trend, staying in cash through chop.

## Run it

```sh
node main.ts
```
